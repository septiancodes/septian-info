Modern personal portfolio and enterprise showcase built with **React 19**, **Vite**, and **Tailwind CSS**. Designed with a high-performance cyberpunk-terminal aesthetic to highlight enterprise retail systems, backoffice ERPs, POS architectures, and full-stack applications.

---

## 🌟 Highlights & Key Features

- **🌐 Dual Language Support (i18n):** Real-time bilingual switching between Bahasa Indonesia (ID) and English (EN).
- **🎨 Modern Dark & Futuristic Aesthetic:** Tailored neo-green accent palette (`#00df8f`), glassmorphism cards, and fluid smooth animations powered by **Framer Motion**.
- **💼 IT Retail & Enterprise Case Studies:** Detailed breakdown of enterprise solutions managing multi-branch retail infrastructure (8 branches + 1 Head Office), POS systems, inventory management, and warehousing.
- **⚡ High Performance:** Ultra-fast bundling with Vite, optimized client-side hydration, and lightweight asset loading.
- **📱 Fully Responsive:** Clean layout across mobile, tablet, and ultra-wide desktop monitors.
- **⚙️ Integrated Admin CMS View:** Built-in dashboard (`/admin` or `Ctrl + Shift + A`) with secure PIN authentication for quick content and translation updates.

## 🛠️ Tech Stack

### Frontend
- **Core:** [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)

### Backend / API (Optional / Local CMS)
- **Runtime:** [Node.js](https://nodejs.org/) + [Express](https://expressjs.com/)
- **File Uploads:** Multer
- **Data Persistence:** JSON-based state storage

## 🚀 Getting Started (Local Development)

### Prerequisites
- Node.js (version 18 or higher recommended)
- Git

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/septiancodes/septian-info.git
   cd septian-info
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   This will concurrently boot:
   - Client: `http://localhost:5173`
   - Express API Server: `http://localhost:5000`

4. **Build for production:**
   ```bash
   npm run build
   ```
   Output files will be generated in the `/dist` directory.

## ☁️ Deployment

This project is optimized for deployment on **[Vercel](https://vercel.com/)** with zero-configuration:

- **Rewrites Config:** Handled via `vercel.json` for single-page application (SPA) routing.
